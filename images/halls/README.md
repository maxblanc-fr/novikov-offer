# Фото залов для NovikovOffer.html

Положите фотографии в папку нужного зала, назвав их по порядку:
`1.jpg`, `2.jpg`, `3.jpg`, … (без пропусков). Поддерживаются .jpg / .jpeg / .png / .webp.

Модалка сама подхватит все файлы по порядку — редактировать HTML не нужно.
